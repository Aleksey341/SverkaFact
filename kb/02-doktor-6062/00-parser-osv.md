# Правила разбора ОСВ (важно для разработки)

## Шапка

В типовой ОСВ 1С **нет колонки «Дата»**. Искать шапку по парам **Дебет/Кредит**, не через общий `findHeaderRow` актов.

Двухуровневая шапка:

1. «Сальдо на начало / Обороты за период / Сальдо на конец»
2. под ними «Дебет | Кредит»

Брать **конечное** сальдо (последняя пара Дт/Кт), плюс обороты за период. Не путать с сальдо на начало.

## Счёт

Номер из заголовка: «по счету 60», «по счету 76.ВА».

## Строки

Пропускать: «Итого», «Счета-фактуры полученные», строку самого счёта `60` / `76.ВА`, документы-регистраторы («Списание с расчетного счета … от ДД.ММ.ГГГГ»).

Оставлять: строки **контрагентов**.

## Контроль

Сумма конечных Дт по контрагентам ≈ итог Дт в файле (эталон ТРИ: 5 950 346,45).
