# 76.ВА / 76.АВ висит, а аванса по 60/62 уже нет

## Суть

На счёте НДС с авансов осталось сальдо, а соответствующий аванс по взаиморасчётам закрыт (поставки / реализации).

## Когда срабатывает

В индексе 76.* есть ненулевое сальдо по контрагенту, которого нет среди «авансных» остатков основной ОСВ.

- Для пары 60↔76.ВА: смотрим **кредит 76.ВА** без Дт-аванса 60.
- Для пары 62↔76.АВ: смотрим **дебет 76.АВ** без Кт-аванса 62.

## Ошибка или право?

Обычно **ошибка закрытия**: не восстановлен / не принят к вычету НДС с аванса в периоде поставки/реализации.

## UI (выданный аванс / 76.ВА)

- **Проблема:** 76.ВА висит, аванса по счёту 60 нет
- **Вероятная причина:** Аванс закрыт поставкой, а НДС с аванса не восстановлен.
- **Что сделать:** Проверить восстановление НДС с аванса в периоде поставки (Дт 76.ВА / Кт 68.02).
