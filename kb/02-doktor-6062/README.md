# Модуль: доктор 60/62 (PRO)

Режим `r6062`. Вход: **ОСВ по счёту** (60 или 62). Опционально второй файл:

- ОСВ **76.ВА** (к 60) — авансовые СФ полученные / книга покупок по сути;
- ОСВ **76.АВ** (к 62) — авансовые СФ выданные / книга продаж;
- либо реестр полученных СФ / книга покупок (эвристика по контрагенту).

Тип второго файла определяется автоматически по заголовку ОСВ.
