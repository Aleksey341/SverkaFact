Вставлять в `SverkaFact _v2.html` / `_v2.1.html`. Синхронизировать с карточками `kb/`.

## Хаб

| Режим | Подзаголовок карточки |
|-------|------------------------|
| Акты | Автосверка двух актов, причины расхождений. |
| Реестры | УТ ↔ БП (или любые выгрузки): дата, документ, сумма. |
| Доктор 60/62 | Развёрнутое сальдо, просрочка, дубли, авансы: Дт 60 ↔ 76.ВА и Кт 62 ↔ 76.АВ. |
| НДС | Два реестра СФ / книги: сумма, НДС, ставка, ИНН, дубли. |
| Эквайринг | Терминал ↔ банк: суммы, комиссия, возвраты, дубли. |

## Доктор 60/62 — форма

**Заголовок второго файла:**  
`ОСВ 76.ВА / 76.АВ или книга покупок (необязательно)`

**Подсказка:**  
К ОСВ по счёту **60** — ОСВ по **76.ВА** (авансовые СФ полученные / книга покупок). К ОСВ по счёту **62** — ОСВ по **76.АВ** (авансовые СФ выданные / книга продаж). Тип файла определяется автоматически.

**Поле порога:** `Аванс от, ₽` (по умолчанию 1000).

**Если второй файл не загружен:**  
Сверка авансов с НДС по авансам не выполнялась. Для счёта 60 загрузите ОСВ по 76.ВА (или книгу покупок), для счёта 62 — ОСВ по 76.АВ.

**Справка в отчёте (60):**  
Вычет НДС с выданного аванса — право, а не обязанность: список справочный.

**Справка в отчёте (62):**  
По полученным авансам СФ обязательна — это ошибка.

## Типы замечаний (severity → колонка «Важность»)

| severity | В UI | Когда |
|----------|------|--------|
| `error` | ошибка | Обязательно исправить (красное сальдо, аванс 62 без СФ) |
| `warning` | внимание | Проверить (развёрнутое сальдо, дубли, нет пары, сумма ≠) |
| `info` | справочно | Право / пояснение (аванс 60 без 76.ВА, даты разные в актах, возвраты эквайринга) |

В формах модулей — раскрывающийся блок «Кратко: …» (`details.faq-box`).
