# База знаний SverkaFact

Локальная методика под **четыре модуля продукта**. Не универсальный «бухгалтерский ИИ» и не доступ к живой базе 1С.

## Три слоя

| Слой | Где живёт | Для кого |
|------|-----------|----------|
| **1. Правила** | Код в `SverkaFact _v2.html` / `_v2.1.html` | Покупатель: детерминированные проверки |
| **2. Карточки** | Папки `kb/01…04` | UI (пояснения) + поддержка клиентов |
| **3. Скилл разработки** | `.cursor/skills/sverkafact-checks/` | Агент Cursor при доработке модулей |

## Samples и severity

- Эталоны: [`_samples/`](_samples/) — `node avito/make-kb-samples.cjs`
- В отчёте 60/62: колонка **Тип** — ошибка / внимание / справочно (см. `severity` в карточках)

## Как пользоваться

1. Новая проверка → сначала карточка по [_template.md](_template.md), потом код.
2. Тексты «причина / что сделать» в HTML **должны совпадать** с полем `ui` карточки (или ссылаться на `id`).
3. Эталонные файлы класть в `kb/_samples/` (обезличенные) и указывать в карточке.
4. Не тащить сюда ГОЗ, ЗУП, ERP-консалтинг, MCP к 1С — это другой продукт.
