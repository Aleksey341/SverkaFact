# FAQ покупателей / Avito

Краткие ответы. Детали — в карточках модулей.

## Общее

**Данные уходят в интернет?**  
Нет. Файлы обрабатываются в браузере на вашем ПК. Интернет нужен только для подгрузки библиотек Excel/PDF при первом открытии.

**Нужна ли 1С / COM / внешняя обработка?**  
Нет. Достаточно выгрузок: акты, ОСВ, реестры, банк.

**Где взять код ПК?**  
В верхней полоске лицензии всегда виден блок «Код ПК». Нажмите на сам код — он скопируется в буфер, появится уведомление «Код ПК скопирован». Работает и при уже активной подписке.

## Доктор 60/62

**Что значит «аванс без СФ»?**  
Для **счёта 60** — аванс **выданный** поставщику (Дт), нет авансовой СФ в **76.ВА** / книге покупок. Это **справочно** (вычет — право).  
Для **счёта 62** — аванс **полученный** (Кт), нет СФ на **76.АВ** — это уже ошибка.

**Какие файлы грузить?**  
1) ОСВ по 60 или 62. 2) Для авансов: ОСВ по 76.ВА (к 60) или 76.АВ (к 62). Книга покупок — запасной вариант по именам контрагентов.

**Почему раньше не показывало ВИННЕРА?**  
Старый разбор ОСВ брал не то сальдо / не находил шапку без колонки «Дата». Исправлено: конечное сальдо + обороты.

**Программа пишет корректировку в 1С?**  
Нет. Excel-лист «Корректировка» — шаблон для ручного создания документа в 1С.

## НДС / эквайринг

**Какие книги — покупки или продажи?**  
Зависит от задачи. Для авансов к 60 — полученные СФ / покупки; к 62 — выданные / продажи. Модуль «Сверка НДС» сравнивает два любых реестра по вашей загрузке.

**Эквайринг не бьётся по дням**  
Часто T+1/T+2 и комиссия. Смотрите соседние даты и нетто в выписке.
