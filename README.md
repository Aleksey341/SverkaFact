# СверкаФакт

Одностраничное приложение для сверки актов и модулей учёта 1С. Пользовательские файлы обрабатываются в браузере.

**Продакшен:** https://sverka-fact.vercel.app

## Публичная структура

| Путь | Назначение |
|------|------------|
| `index.html` | Production-приложение |
| `api/license/migrate.js` | Одноразовая миграция ранее выпущенных legacy-лицензий |
| `vercel.json` | Настройки Vercel |
| `.vercelignore` | Исключение внутренних материалов из deployment |

Внутренние инструменты разработки, база знаний, тестовые сборки, KeyGen и приватные ключи в публичный репозиторий не коммитятся.

## Лицензирование

Новые лицензии используют асимметричную подпись SF2: приложение содержит только публичный ключ и может проверять лицензию офлайн.

Ранее активированные лицензии продолжают работать из локального хранилища браузера. Для ещё не активированных legacy-ключей используется одноразовая миграция через серверный endpoint; принимаются только заранее внесённые в allowlist выданные ключи.

## Деплой

Push в `main` запускает deployment Vercel. Framework Preset: **Other**.
