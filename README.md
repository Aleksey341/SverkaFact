# СверкаФакт

Одностраничное приложение для сверки актов и модулей учёта 1С. Пользовательские файлы обрабатываются в браузере.

**Продакшен:** https://sverka-fact.vercel.app

## Публичная структура

| Путь | Назначение |
|------|------------|
| `index.html` | Production-приложение |
| `vercel.json` | Настройки Vercel |
| `.vercelignore` | Исключение внутренних материалов из deployment |

Внутренние инструменты разработки, база знаний, тестовые сборки, KeyGen и приватные ключи в публичный репозиторий не коммитятся.

## Лицензирование

Лицензии используют асимметричную подпись SF2 на Ed25519.

В приложении находится только публичный ключ. Приватный ключ используется только офлайн для выпуска лицензий и не должен попадать в GitHub, Vercel или клиентский HTML.

## Деплой

Push в `main` запускает deployment Vercel. Framework Preset: **Other**.
